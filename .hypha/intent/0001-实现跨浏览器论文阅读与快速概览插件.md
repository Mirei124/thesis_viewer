# 实现跨浏览器论文阅读与快速概览插件

## Objective

按已定稿规划实现 Chrome/Firefox 论文阅读插件，帮助相关领域学者快速确定论文做了什么。主 agent 维护总体进度，逐块拆解小目标，以总体实现进度、当前细节目标清单、相关背景知识组成子 agent 初始上下文，验收后回填。

- [ ] Chrome/Firefox 实际扩展可独立阅读 PDF/论文 HTML；本地解析、自配兼容 API，无必需自建服务器或 Moonlight 依赖。
- [ ] 三行 contributions 与详细摘要符合定稿内容、证据定位和材料覆盖要求；核心贡献与相对创新区分。
- [ ] 基础阅读、持久化高亮、本地 cite 浮窗、划词/句子翻译及错误恢复完成。
