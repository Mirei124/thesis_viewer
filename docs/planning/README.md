# 跨浏览器论文阅读插件：规划入口

更新：2026-09-22。状态：规划 v1 定稿，可交给实施 agent。DOM 调研、架构、核心功能及两类摘要设计已确定；实现与模型实测尚未进行。此目录是交接的事实来源，不需要依赖本次聊天记录。

## 用户已确认

- 为任意论文 PDF／网页提供独立阅读与 AI 总结，参考 Moonlight 体验，不是 Moonlight 增强脚本。
- 同时支持 Firefox 与 Chrome。
- 本地解析；用户配置兼容 API 地址、密钥、模型；无必需自建服务器。
- 面向相关领域学者。三行摘要采用引言末尾的三条 contributions 风格，少写背景，聚焦三项有证据的贡献。
- 首版以快速确定论文做了什么为主：基础阅读、高亮、正文 cite 浮窗、划词/句子翻译、三行摘要和详细摘要。
- cite 浮窗仅使用对应参考文献条目、标题/作者/年份、DOI/原文链接，已有本地摘要则显示；不自动联网补全。
- 详细摘要按引言取核心问题/动机/方法总览，方法部分取具体步骤/核心贡献，实验部分取模型/数据集/baseline/消融有效性，并指出有依据的未覆盖局限。
- 详细摘要默认 800–1500 中文字，公式仅保留理解机制所必需的；核心贡献和相对创新明确区分。
- 本 session 负责 DOM 调研、开源复用、整体架构、功能细节和提示词规划；其他 agent 决定具体代码逻辑并实现。
