# 实施顺序、验收与交接

本文件只规定步骤、模块输入输出和可验证行为。具体代码、状态管理、排版算法、组件划分由实施 agent 自行决定；不得擅自扩大首版范围。阅读入口见 [README](README.md)。

## 1. 分阶段交付

| 阶段 | 前置 | 实施内容 | 可审阅交付与退出条件 |
|---|---|---|---|
| M0 双浏览器骨架与可行性 | 无 | WXT + TS + React，两个 MV3 构建；独立阅读页、选项页、按需权限；PDF.js 本地 worker | Chrome 和 Firefox 实际加载成功；打开同一 PDF，有文字层、目录；CSP 无远程脚本。先验证 URL 下载与自配端点请求，不等全部 UI 写完 |
| M1 阅读核心与导入 | M0 | 本地/URL PDF 导入、页码/缩放/旋转/查找/目录/缩略图、文件错误处理、位置恢复 | 17 页 SmartTrim 无需全文渲染即可翻页；离线可重开已保存文件；损坏/密码/扫描输入明确降级 |
| M2 文档解析与证据基础 | M1 | 稳定块、双栏顺序、章节、原坐标、文本映射、coverage、版本/hash、参考文献和 citation occurrence | 解析首尾页、主文与附录不静默丢失；可从 block/evidence 跳到原文；歧义文献标记为 ambiguous 而不是错配 |
| M3 高亮与 cite 浮窗 | M2 | 选区菜单、持久化高亮、引用匹配与浮窗、已有本地摘要关联 | 跨行选区缩放/旋转/重开位置准确；点击 cite 不先离开正文；多引文和无链接引文有匹配/候选/失败状态；无自动网络调用 |
| M4 模型接口与翻译 | M2 | 配置地址/模型/密钥、能力配置、任务取消/错误/缓存、选词/选句翻译 | 以 mock 验证正常/流式/错误/取消/竞态；真实 API 由用户提供时验证；网页内容脚本拿不到密钥 |
| M5 论文概览流水线 | M2+M4 | 证据提取/账本合并、三行摘要、六部分详细摘要、校验/一次修复/重生成版本 | 结构符合 03-prompts；创新与贡献分离；包含模型/数据集/baseline/消融；证据可回跳；长论文完整覆盖而非截断 |
| M6 HTML 全文与落地页 | M2+M5 | 学术 adapter、Readability 回退、安全快照、HTML anchor、abstract-only 状态 | arXiv HTML/通用 article 可导入；网页摘要不冒充全文；PDF 和 HTML 共享概述契约但不混用坐标 |
| M7 双浏览器回归与交付 | M3–M6 | 实际扩展安装、失败路径、存储迁移、性能检查、打包与使用说明 | 输出两端产物、已测版本矩阵、已知限制、验收记录；未测试项如实列出 |

阶段不是并行 agent 指令。执行者可自行组织代码工作，但应先解决 M0 的平台与生命周期风险，再投入复杂摘要 UI。任何更改已确认范围/生成目标的决定需回到用户，不由实施者把不便实现的核心功能悄悄挪到后续。

## 2. 模块接口应先确定

不用强制具体类名，但需要以下独立职责与输入输出：

- `ImportSource -> DocumentDraft + OriginalAsset + ImportWarnings`：下载/网页快照/文件选择只负责获取，不调用模型。
- `DocumentDraft -> StructuredDocument + Coverage + ReferenceIndex`：本地解析可取消、可报告页级进度。
- `Anchor -> NavigationResult`：PDF/HTML 两个视图实现同一定位结果，明确 exact/paragraph/page/unresolved。
- `CitationOccurrence -> ReferenceCandidates`：结果含置信依据、原始条目及跳转位置；不暗中在线搜索。
- `Selection + NeighborContext + TranslationOptions -> TranslationResult`：选区快照/任务 ID 必须参与防竞态。
- `StructuredDocument + PromptProfile + ModelConfig -> GenerationJob`：任务持久化、可取消、可恢复已完成阶段。
- `Candidate + EvidenceIndex -> ValidationReport`：区分结构错误、证据不存在、引句不存在、语义待核对。
- `Repository`：文档、块、引用、高亮、生成、job 的事务、迁移、删除；模型密钥不进入结果记录。

数据字段的完整语义见 [架构](02-architecture.md)。建立这些契约后再选内部算法，避免摘要功能与 PDF DOM 选择器绑死。

## 3. 测试资料与关键用例

| 资料/场景 | 目的 | 通过标准 |
|---|---|---|
| SmartTrim v2 | 双栏、公式、内部引用、表格、方法/消融 | 方法顺序可读；无重复页眉干扰；准确区分 FLOPs 与延迟；同一图表数值不会跨列错拼 |
| 自制带 named/explicit destination 的 PDF | 链接与坐标确定性 | 单引文、多引文浮窗能返回正确条目；章节/图表链接保持原导航 |
| 自制无链接编号和作者年份参考文献 PDF | 不依赖 PDF 内部链接 | 确定匹配正确；同姓同年歧义展示候选；未知不猜 |
| 扫描件、加密、损坏、超限 PDF | 错误边界 | 扫描可阅读但不虚构文本；密码错误可重试；损坏/超限不发模型 |
| 只有摘要的 HTML | 输入覆盖 | 三行不超出摘要；方法/消融显示材料不足 |
| 含 MathML 和表格的论文 HTML | 网页保真与清理 | 关键结构可读；无脚本执行；公式无法恢复时有原文入口 |
| 长文与少量乱码页 | 分块覆盖 | 所有合格正文块被处理；缺页清楚标出；没有只总结前几页 |
| mock 401/429/500/超时/截断 JSON/坏引用 | 模型可靠性 | 错误清晰，有限重试，取消生效，坏结果不替换缓存 |
| 打开两份文档/两个同文档标签 | 隔离与去重 | 不串文档摘要、不重复并发任务、不用旧翻译覆盖新选区 |
| 生成中关闭/刷新/浏览器重开 | 生命周期 | 在途任务变 interrupted；缓存保留；不悄悄再次付费生成 |
| 缩放 50/100/200%、旋转 90/180°、重开 | 高亮/引用坐标 | 文本锚点与视觉区域一致；证据跳转回退精度诚实 |
| 默认收起目录、窄屏、键盘 | 阅读体验 | 原文/摘要可访问；浮窗不遮住全部选区；Esc 与焦点返回正确 |

持久化删除需保证文档关联块、引用、高亮、任务和原文件同步清理；用户删除正在生成的论文后，晚到结果不能把它复活。重生成不删除旧高亮或改动原文。

## 4. 双浏览器验证方式

Chrome/Chromium：用持久 context 加载实际构建的扩展做端到端测试。遵循 [Playwright 扩展测试文档](https://playwright.dev/docs/chrome-extensions) 的受支持加载方式，不把普通网页测试当扩展测试。

Firefox：使用 [web-ext lint / run](https://extensionworkshop.com/documentation/develop/getting-started-with-web-ext/) 或 `about:debugging` 临时加载实际产物，再在真实 Firefox 验证功能。普通 Playwright Firefox 网页模式通过不等于 Firefox 扩展验证通过。临时加载不能完整代表签名安装/重启权限行为，交付记录要区分。

最低支持版本由 M0 实际兼容 API 和已测浏览器确定并写入 README/manifest；首版目标是实施时桌面稳定版 Chrome/Firefox，ESR/移动端不默认承诺。不能只提交“WXT build 成功”作为双浏览器完成证据。

测试命令由实现仓库提供统一 scripts：typecheck、unit、build:chrome、build:firefox、lint:firefox、e2e:chromium；Firefox 实际验证脚本或清晰的人工步骤另附。针对解析/锚点/状态机用单元测试，针对入口/权限/阅读链路做集成测试；不为静态文案堆镜像测试。

## 5. 完成定义

- [ ] 两端真实扩展可打开 PDF/论文 HTML，配置自定义模型，核心行为一致。
- [ ] 不依赖 Moonlight 账号、接口或暴露的 PDF.js 全局对象。
- [ ] 三行摘要采用引言末尾三条 contributions 风格，突出互补的实质贡献、少写背景，不固定套问题/方法/结果；详细摘要覆盖用户指定章节维度。
- [ ] 创新与贡献区分；实验模型、数据集、baseline 和消融有效性说清；局限推断有依据且不猜作者意图。
- [ ] 每项关键事实可定位原文，缺失数据/引用匹配失败有明确状态。
- [ ] cite 浮窗、高亮、划词/句子翻译及恢复机制通过关键用例。
- [ ] 用户文件、密钥、选区请求不被错误发到非指定服务；无自动跨论文搜索或隐藏生成。
- [ ] 文档记录实际测试的版本、API 能力、样例、性能、失败项；没有 API 时标“真实模型未测”，不能交付为全部验证。
- [ ] 产物有安装/临时加载说明、设置说明、本地数据删除入口、许可证声明。

性能初始目标（工程目标，不是已测承诺）：普通 20 页文本 PDF 可在数秒内开始阅读；页面仅渲染可见及邻近页；解析时 UI 可响应；缓存结果无额外模型请求。测试记录硬件、文件大小、浏览器版本与首屏/全文抽取时间，模型生成延迟单列，不拿固定秒数约束远端服务。

## 6. 候选功能：均未纳入首版

供用户后续选择，默认不实施、不建空白占位导航：

| 候选 | 对快速理解论文的帮助 | 新增成本/依赖 |
|---|---|---|
| 摘要/高亮 Markdown 导出 | 便于记录与交给其他工具 | 低；需约定来源链接、证据和版本格式 |
| 方法图/表格解释 | 对结构复杂论文较有帮助 | 中高；区域截取、视觉模型、表格定位与额外传输 |
| 单篇带出处问答 | 对具体疑点追问 | 中；检索、会话、上下文预算、问题范围控制 |
| 术语词典 | 跨领域阅读更有帮助 | 低中；对本项目默认学者读者优先级较低 |
| 自动贡献/方法/结果高亮 | 帮助定位关键句 | 中；需分类和误标处理；手工高亮先完成 |
| 逐页/全文翻译 | 长篇非母语阅读 | 中高；请求量、术语一致性和并排布局 |
| 外部引用摘要补全 | 点击引用即可预判另一篇论文 | 中；外部 API、同名版本消歧、限流和缓存 |
| OCR/复杂版面解析 | 支持扫描件和难抽取 PDF | 高；本地 OCR 模型体积/性能或可选服务器，需重新讨论 |
| 笔记/批注/文献文件夹 | 长期管理 | 中；偏离当前快速判断主目标 |
| Quiz、推荐、云同步 | 学习/管理扩展 | 中高；当前目标相关性低 |

## 7. 给接手 agent 的启动指令

先读本目录 README、02、03、05，确认定稿状态；把文档中的用户确认范围作为约束，从 M0 开始实现。只把已经实测的部分报告为通过。具体实现逻辑可自行决定，若某项核心功能确有不可行条件，展示证据和降级方案，不自行删除需求。不要实现候选功能，不要为复刻外观引入 Moonlight 服务依赖。优先打通“导入 → 阅读 → 三行/详细摘要 → 原文核对”，并完整交付高亮、cite 浮窗和选区翻译。
