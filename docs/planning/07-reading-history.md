# 阅读历史与活动视图

2026-10-04 用户要求：左侧历史阅读 tab；在线标题+URL，本地标题；reader首页保留现有首屏，下滑展示类似GitHub的阅读数量热力图与时间排序历史。用户选择“只保存历史；点击本地项时重新选择文件”。

## 交互与展示

- 已打开PDF：左边第三个“历史阅读”tab，沿用现有竖向tabs键盘、可调宽面板及移动端收起行为。最近阅读在上、标题可换行；在线行另有网址，本地不显示文件路径／网址。
- 阅读顶栏新增“返回首页”，安全取消当前会话与清除PDF fragment，回到首屏；历史与现有缓存保留。
- 首页（未打开PDF）：现有欢迎、文件及URL入口占首屏，历史区域在其下方；上方视觉与交互保持接近既有布局。阅读期间历史只通过侧栏查看，不把整块dashboard追加到PDF页尾。
- 首页历史区域：近一年日历热力图、按日去重阅读篇次与活跃天数摘要、按最近打开时间排序的历史列表。色阶0/1/2/3–4/5+，图例及逐日数量可访问文本（不只靠颜色）；周／月标记，窄屏只图表内部横滚，页面不溢出。
- 列表支持标题／URL搜索、分批加载更多、空记录／无搜索结果／存储失败提示，首页和侧栏共用数据与行组件。显示最近打开日期时间，可清空历史（明确确认；不删除高亮、翻译、概览或PDF）。
- 在线项点击在当前reader重新打开原HTTPS地址，复用现有host按需授权；不能把permission.request放到await之后。记录网址文本可复制／按现有链接安全规则打开；只实际PDF成功后入历史。
- 本地项点击提示对应标题并打开原文件选择器，不保存PDF字节或文件路径；选择后按既有本地导入，不承诺凭记录直接还原File。

## 记录与统计

- 成功加载PDF后记录，失败、HTML、取消、超限不记录；一次导入至多记录一次，页码／缩放／旋转不增加计数。记录当前打开时间而非修改文件时间。
- 列表同来源去重：本地按SHA256；在线按规范HTTPS URL（保留query，去fragment）。每行firstOpened/lastOpened/openCount更新。在线和本地同内容可保留各自来源，显示符合用户要求。
- 活动按用户打开时的本地日历日计数：同内容hash同一天只计一次，即从在线／本地重复打开也不双计。使用持久civil date YYYY-MM-DD，不从UTC截字符串；DST与闰年用日历操作而非固定24小时步进。统计“成功打开过的不同PDF”，不宣称已读完／阅读时长。
- 热力图为最近365天截至今天，不展示未来日；历史列表没有自动删旧限制，可按需分页。旧版本没有阅读历史，不倒填或猜测旧阅读时间。
- 本地IndexedDB独立库，用事务原子更新历史与日活动，避免并行reader覆盖写入。只保存标题、来源URL或内容hash、时间及次数；不保存PDF字节、API密钥或内容摘录。storage错误不阻断阅读；其他reader完成记录或清空后刷新视图（BroadcastChannel或window focus刷新即可）。

## 标题与边界

优先使用非空且非通用占位的PDF metadata Title；元数据缺失时，可保守提取第一页顶部显著大字连续标题行，不能把作者／Abstract／arXiv边栏误当标题；识别不可靠回退文件名去.pdf／URL末段。保存title来源方便后续改进，不为标题发模型／联网请求。所有文本React纯文本渲染，URL只有有效无凭据HTTPS入口。保持B085共享zoom、B083自动概览和B088英文术语不变。
