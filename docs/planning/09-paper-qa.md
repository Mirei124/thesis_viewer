# 论文问答（B107用户确认与实现契约）

2026-10-31用户确认开始实现，取代B106研究报告中的候选默认值。基础为本地PDF.js解析、用户现有兼容API设置，不依赖额外服务器或embedding服务。

## 确认范围

- 三档输入：“实验之前／正文全文／全文含附录”，新对话默认实验之前。实验之前以第一处识别到的实验／结果章节为阅读顺序边界，不是散选所有非实验段；没有可识别边界的论文保留合格正文。
- 正文全文排除参考文献和附录；全文含附录包含全部可提取段落，包括参考文献。显式选区可补入范围外对应原文，选区不是唯一证据。
- 已有回答后扩大范围只追加尚未发送的原文，P别名不变，之前的system、原文消息和问答都不改写。降档也不撤回已读内容；需要更小上下文须新建对话，界面明确提示。
- OpenAI兼容请求仍会重发完整messages；追加式历史旨在保留稳定前缀以利服务商缓存，不是客户端只上传增量的有状态协议，也不保证缓存命中。
- 单次输入128000／输出64000为两个独立QA限制，K=1000。输入采用估算并预留6400安全量，超限明确拒绝，不静默截原文或历史；服务商真实总窗口另须容纳输入和输出。当前没有精确通用tokenizer，临界场景另验，不把估算称作所有模型严格上界。
- 按论文内容hash本地保存多个会话，新建、切换、删除；只加载轻量列表，选中后读完整对话。不同PDF版本隔离，来源提取版本变化时不重写旧会话，要求新建。
- 文字／可提取表格＋流式，暂不做图像问答、OCR、跨论文、网络检索或embedding。完整可提取文字不等于模型读取了PDF图像／表格完整版面。
- 复用用户API配置，不改详细概览的默认输入／复核／非流式流程。QA独立使用64K输出上限，不修改全局模型设置。

## 前端

阅读器右侧新增“论文问答”，与论文洞见／搜索／工具并列。PDF选区浮窗新增“选区提问”，带原文及页码到草稿，不自动请求模型。

“本篇对话”在同一侧栏内显示列表，不弹居中窗口；删除确认也内联。原文来源仍使用既有原文弹窗和PDF定位，与文献引用卡片区分。

流式过程中只展示回答正文，不展示JSON／reasoning；来源检查完成后才启用按钮。停止保留已收到文字，未完成回答不进入后续已提交模型历史；可重试。切换研究面板保留未发送草稿，完成在后台的回答重新打开时可见。

来源ID／原文位置校验不等于语义正确，重要事实仍需回查。格式失败最多一次修复，传输／来源失败不额外收费重试；修复历史原样保留，以利后续前缀复用。用量显示服务商已报告的输入／输出／缓存计数，包含修复；未知时明示不完整。

## 本地数据与生命周期

独立IndexedDB保存问题、答案、选区、已提交messages（包含已加入的论文原文上下文）、来源映射ID及用量，不保存APIkey或PDF二进制。阅读历史库仍仅保存原有元数据，清空阅读历史不删除问答会话。

默认会话保存并不自动恢复本地PDF文件；要定位原文仍需重新选择相同文件。删除会话只删除对应会话，其他高亮／阅读历史／概览不受影响。

持久化显式字段白名单；revision比较防其他页面覆盖，删除排队／tombstone防晚写复活。冲突先停止请求，不覆盖远端；存储失败内容暂存本页，可切换后找回，须提示勿关闭页面。保存恢复后重新持久化；不能承诺进程强制终止时最后一个字符已落盘。

关闭／替换文档／离开页面取消请求并尽力保存；流中每秒checkpoint。PDF缩放／滚动不取消问答，也不创建第二个PDF文档或整篇截图；遵守B101位图回收策略。

## 验收与限制

B107包含362项全项目测试、类型检查、双端构建、独立Chromium阅读器构建回归及DeepSeek三轮真实调用；详见[验收](../implementation/evaluations/B107.md)。Firefox真实扩展页面、128K边界、扫描PDF和很长历史仍需实际环境补验，不以构建通过代替运行验证。
