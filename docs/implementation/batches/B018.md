# B018：兼容 API 请求与按需端点权限

日期：2026-09-26。执行 agent：`/root/b018_provider_permission`。主 agent 验收：代码、mock 测试和双端构建通过；真实浏览器／端点验证待测。

- 新增 `apiPermissions`：从 B017 已校验的 endpoint 生成最小 host match pattern，并以同步调用的 `permissions.request` 返回 granted、unavailable、denied 或 request-failed。manifest 保持可选权限，仅增加明确的 `http://localhost/*` 和 `http://127.0.0.1/*`，不开放其他 HTTP。
- 新增 `compatibleProvider`：只在 base URL 后追加一次 `/chat/completions`，发送调用方传入的 `model/messages/stream`；只有有 key 时设置 Bearer。支持非流 `choices[0].message.content` 与带 `[DONE]` 的 SSE `choices[0].delta.content`，接受 `AbortSignal`。
- 错误语义区分 aborted、network、401/403、404、可识别的上下文超限、429/Retry-After、5xx、其他 HTTP 与无效响应；无自动重试、协议切换、模型列表、UI、任务队列或缓存。
- 主 agent 审查后复跑 `pnpm test`（9/9）、`pnpm typecheck`、`pnpm build:chrome`、`pnpm build:firefox` 与 `git diff --check`，均通过。
- 未完成：没有真实用户端点、真实 Chrome/Firefox 权限提示或 B017 options 页交互验证。B019 必须在受信任 extension 页的用户点击处理函数中、任何 await 前直接调用 `requestApiHostPermission`，授权后再调用 provider；翻译 UI、选区边界、任务、缓存和竞态仍为后续独立范围。
