# B004：URL PDF 导入与按需来源权限

日期：2026-09-22。执行 agent：`/root/b004_url_import_permission`。主 agent 验收：通过。

## 目标与范围

实现用户在阅读页明确提交 HTTPS PDF URL 后的按需来源权限、无 cookies 下载、实际 PDF 校验与既有首屏渲染复用；不引入常驻 host permission、网页采集、持久化或模型功能。

## 验收边界与接续

- Chromium 已验证未授权前不会向目标 host 发请求；Firefox 已验证批准权限后的 URL 下载和渲染。
- 权限拒绝、HTTP/HTML 响应及取消竞态仍需随完整导入功能回归，不能提前标记为浏览器已测。
