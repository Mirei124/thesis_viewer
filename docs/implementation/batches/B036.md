# B036：直链 PDF 入口回归与 Chrome 验证准备

## 任务包

- 执行 agent：`/root/b036_url_pdf_chrome_regression`
- 范围：仅验证和强化实际返回 PDF 的 URL 导入边界，并准备 M7 Chrome 关键链路手动回归；HTML 论文页、网页采集、快照和 HTML anchor 明确排除。

## 目标与结果

| 目标 | 结果 | 证据 |
|---|---|---|
| B036-01 直链 PDF 入口 | 已完成 | 新增 `urlPdfImport` 纯函数；仅接受下载字节的 `%PDF-` 签名。HTML（含 BOM／DOCTYPE）及其他非 PDF 均被拒绝；权限模式只包含提交 URL 的 scheme 与 hostname。 |
| B036-02 Chrome 回归准备 | 已完成 | README 增加可执行的 Chrome 手动清单：本地 PDF、W3 URL PDF、HTML 拒绝、翻译／两类概览与权限拒绝；明确 `arxiv.org/html` 不支持。 |
| B036-03 自动验证 | 已完成 | 主 agent 验收运行 `pnpm test`（12 files、72 tests）、`pnpm typecheck`、`pnpm build:chrome`、`pnpm build:firefox`、`git diff --check`，均通过。两端仍有既有 reader chunk 大于 500 kB 的构建警告。 |

## 主 agent 验收

通过代码与自动验证验收；没有扩大为 HTML 导入，也没有新增网页权限或模型协议。Chrome 的真实扩展、真实端点与权限 UI 尚不能由构建／mock 替代，保留为用户 M7 验证。

## 下一步

用户在 Chrome 中按 README 的 M7 清单完成关键链路验证后，主 agent 记录版本、结果与任何已知限制，再决定 M7 是否可以结束。
