## 二、当前细节目标清单

1. 读取 PDF.js Link annotations，在连续阅读各页（含非 active 页）生成对齐链接区域。缩放、旋转、页自身 rotate/CropBox 按 page viewport 坐标转换，不硬算 y；切换 PDF／缩放时旧区域不得残留。处理 malformed rect 或 annotation 读取失败，不拖垮阅读。
2. 原生 HTTP(S) 外链使用可键盘访问的 anchor，新标签打开、noopener noreferrer。不执行脚本／launch／file 或未经验证协议，不需要增加 host permissions 或自动访问链接内容；使用 PDF.js 提供的合法 URL，不能从 unsafeUrl 猜地址。
3. 内部 named／explicit destination（PDF ref 和数字页索引）能跳到正确页面，复用 reader 页码／历史导航；尽量支持 XYZ／FitH 等目标位置，未知或失效目标可见降级提示，不破坏当前视图。与原有 cite marker 浮窗相交时保留 cite 优先，不遮盖无链接正文的文字选择／高亮／翻译。
4. 有意义的 URL／坐标／destination 测试，typecheck 和全套测试。主 agent 对用户 PDF code 点击、另页链接、内部跳转、缩放／旋转、选择／cite 回归做浏览器验收并执行双端构建、最终提交。
