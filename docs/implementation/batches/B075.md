## 三、相关背景知识与执行边界

- Chrome 官方支持以 `--pack-extension=目录` 和 `--pack-extension-key=PEM` 生成 CRX；第一次不传 key 会生成私钥。此项目 Chromium 在 `/usr/bin/chromium`，Chrome 扩展目录为 `.output/chrome-mv3/`。目前 `package:chrome`、`package:firefox` 分别运行 `wxt zip --browser ...`；`.output/thesis-viewer-0.1.0-chrome.zip`、`-firefox.zip`、`-sources.zip` 已通过 B074 验收。
- PEM 是私钥，只保存在忽略的 `dist/` / `.output/` 中；脚本复用既有 key，不能把 PEM 添加到版本库。`dist/` 当前为空，已由用户指定输出。若没有 PEM，首轮生成并放入 `dist/`；后续优先 `dist/` 中的私钥，不另生新 key。CRX/PEM/ZIP 命名清晰，可含版本或目标。
- 子 agent 不改文档、Hypha或提交；主 agent 独占进度和验收。本批是打包产物，不改变扩展运行时或 Firefox 签名要求。
