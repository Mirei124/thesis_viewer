## 三、相关背景知识与执行边界

- 用户将原 URL `deekseek` 明确更正为官方 `https://api.deepseek.com/v1`；默认模型指定 `deepseek-flash`。DeepSeek 官方 Chat Completions 文档列出该模型和 `response_format: { type: 'json_object' }`，官方接入示例给出 `/v1/chat/completions`。结构化输出仍是可关闭的显式能力，其他兼容端点可能不支持；不因模型名自动推断/回退。
- 当前 `model-config:v1` 存储含 `streaming`，新读取逻辑须接受旧对象但返回无 `streaming` 的配置。只改变缺省值，不覆盖已保存的 baseUrl、model、structuredOutput 或 outputLimit。API key 仍按已实现的 session/local 边界保存。
