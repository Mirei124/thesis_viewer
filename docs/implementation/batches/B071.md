## 三、相关背景知识与执行边界

- B070 的 [质量评估](evaluations/B070.md)确认单个 alias 可能包含多个原始 PDF 文字项；目前 `src/pages/reader.tsx` 的 `renderInlineEvidence` 将它们渲染为 `[n.1]` 等按钮，展开区没有连贯原文。`VerifiedEvidenceRef.evidenceIds` 保存经过验证的原始成员 ID；`evidenceLedger.ledger.candidates` 含原始 `quote`、`blockId`、section，`extraction.pages` 含 PDF.js 块和位置；`locateEvidenceCandidate` 负责跳转精度。
- 用户要求增加合并展示，不要求改变模型输入或重做摘要。可以在视觉上将可连续的原始 quote 串成可读文本，并让各片段仍可点击；遇到不同页、不同栏、明显阅读顺序断裂或不可定位时分段显示。不把 PDF.js source order 本身当跨栏顺序证明。只有常规空格／行末连字符等有依据的排版规范化可用，不能补写原文不存在的内容。
- 现有 `details/summary` 为原生 disclosure；现代 HTML 指南支持该模式、要求 summary 为首子节点且勿在 summary 内嵌交互按钮。扩展需兼容 Chrome/Firefox；保持键盘、屏幕阅读器可用。`pnpm replay:evidence` 不调用模型，五篇样本在 B069/B070 评估中有路径。主 agent 独占总体进度、Hypha、`docs/implementation/**`、浏览器；子 agent 仅修改约定的引用展示代码、直接测试与文案，不改证据构造、提示词或跟踪文档。
