## 相关背景知识
选区由文字层 mouseup 捕获，已存高亮由页面 click 命中；工具栏按钮以 mousedown preventDefault 保留原选区。外部 pointerdown 不阻止浏览器默认操作，以允许重新选字。

## 原因与修改
reader.tsx 的 document pointerdown 监听器错误地豁免整个 pdfPageRef，导致 PDF 页面内所有点击都不关闭旧控件。移除此豁免，保留工具栏和翻译浮窗内部交互；原有 citation、Escape 和高亮命中逻辑保留。

修改前构建：选中文字后点击 .is-active-page .textLayer，toolbar=true，复现残留。
修改后：同一操作 toolbar=false、浏览器选区为空；重新选字后创建黄色高亮成功，工具栏进入编辑态；改绿色成功且内部点击保留工具栏；点击 PDF 正文关闭编辑工具栏并保留绿色标注；Escape 关闭选字工具栏。高亮区域原生鼠标点击与内部语言选择另执行回归，见本批运行结果。
