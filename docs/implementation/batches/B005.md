# B005：页码导航、缩放、旋转与文字层同步

日期：2026-09-22。执行 agent：`/root/b005_reader_controls`。主 agent 验收：通过。

## 目标与范围

为已加载的本地/URL PDF 实现上一页、下一页、跳页、缩放和顺逆时针旋转；文字层必须与 canvas 共享缩放/旋转。未实现搜索、目录、缩略图、持久化或其他相邻功能。
