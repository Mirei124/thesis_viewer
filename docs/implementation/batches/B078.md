## 三、相关背景知识与执行边界

- 保留本地 PDF 大小／页数、签名验证、内容哈希、逐页文字锚点与证据校验；没有改变概览协议或网页采集范围。
- 修复前 `loadPdf` 把内容键计算结果、`extractPageBlocks` 启动和保存视图恢复排在首次 `renderPage` 成功返回之后。就绪状态的自动缩放可发起后继渲染，取消首次渲染后直接 `return`，留下 extraction idle。现在首次渲染与哈希并行；索引不依赖首次渲染是否被替代，仍区分真正渲染失败与后继渲染接管。
- 两个按钮原本都在同步点击处理函数中调用同一文件 input 的 `click()`，并在 `change` 后清空值。Playwright 接管原生文件窗口时会报告 `filechooser`，可通过 `setFiles`／CLI `upload` 完成选择；不能以自动化会话中未显示系统窗口判断按钮失效。子 agent 静态检查发现视觉隐藏的输入框可能进入 Tab 顺序；已加 `tabIndex={-1}`。
