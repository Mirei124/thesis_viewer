## 三、相关背景知识与执行边界

- Chrome `activeTab` 让用户点击 action 时可读当前标签 URL；`action.onClicked` 需要无默认 popup。工具栏只把可信的 HTTPS 直链或 arXiv PDF 路由交给既有 reader，reader 继续验证 `%PDF-`。`/abs`、`/html`、网页和 `file:`、`blob:` 均不走此入口。
- 三行包仍最多 12 条、每条 600 字符，独立请求、短别名和原始 quote/anchor 校验不变。几何约束重建拆散的数字，允许前面事实完整而段尾残缺的 PDF passage 入选；提示模型忽略未完分句，外推必须标注预测条件。
- 子 agent 只实现 B076-01 并报告验证；主 agent 完成 B076-02、B076-03 和追踪。The Moonlight 是质量参考，不用其文字代替 PDF 证据。
