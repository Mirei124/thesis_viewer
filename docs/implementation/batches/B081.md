## 三、相关背景知识与执行边界

规划仍要求局限正文区分作者明确陈述、实验范围推断与当前材料不足，但当前自动分类仅检查来源候选槽位。该槽位由标题启发式生成，与段落论证不等价，因此删除自动尾标而保留正文与引用是更可信的呈现。规划中的输出字段说明同步删除过期 `limitationKind` 要求。模型请求、提示词和概览文本缓存协议未改。

服务商 `usage` 是可选字段。小字用量栏仅统计本次打开 PDF 后成功返回响应的论文洞见请求，包括随后未通过本地 JSON／证据校验的响应；中断、网络失败、服务商未报告的用量无法估算。分母取服务商报告的前缀缓存命中与未命中 token 之和；它不是“本地摘要缓存命中率”。用户若从本地缓存恢复摘要，本次请求数为零。
