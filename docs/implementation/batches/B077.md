## 三、相关背景知识与执行边界

用户已明确指浏览器工具栏扩展图标的原生三点菜单，不是 reader 内“更多阅读选项”。[Chrome contextMenus 官方文档](https://developer.chrome.com/docs/extensions/reference/api/contextMenus)与[Firefox menus 官方文档](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/menus/ContextType)均支持 `action` 上下文；manifest 需要 `contextMenus` 权限。扩展只能增加自己管理的条目，浏览器固定菜单项仍由浏览器管理。原有 `action.onClicked` 不带 popup，继续负责 PDF 判定。菜单仅打开现有 `reader.html`、`options.html`，不采集网页内容。
