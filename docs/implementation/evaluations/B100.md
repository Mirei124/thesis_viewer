# B100：完整引言、相邻上下文与失败原因

2026-10-22，用户批准问题与动机完整引言、失败原因区分，并要求扩充相邻段触发词，平衡证据完整性与输入长度。

## 实现

- 问题与动机改为完整的已识别Introduction正文，仅去除明确页码、预印本页眉等噪音。方法正文完整保留；附录、参考文献仍全部排除。
- 轻筛选按原始命中段补选邻段；扩充段首this/these/such gap、question、limitation、observation、challenge等指代，to address、therefore、however等衔接语及中文对应表达。普通段中提到这些词不会无条件扩展。
- 同小节、最多相差一页、正文读序约束；只对原始种子扩展，不递归。短公式与紧随的变量定义可作为完整组补选，最多两跳。标题、表格、图注、列表不作为无条件续段；明确页眉噪音可跳过。
- 每次筛选补选预算max(768,min(2400,ceil(原始种子估计token/2)))，同一栏目合计最多2400估计token。整段超限则跳过并诊断，不截断原文或引用成员；请求仍受既有输入加输出总预算约束。
- 区分未选到来源、模型报告不足、请求失败、格式修复失败、引用校验失败、上下文容量不足；双语提示与安全诊断。保留有效分批结果，不缓存失败结果。格式错误仍最多修复一次；无来源不调用模型；未知引用不放宽校验。修复放不进窗口归为容量不足，可选复核放不下仍保留有效初稿。
- 选择器v3、详细提示v20隔离旧缓存；没有增加embedding、模型调用阶段或权限。
