## 原因与修正

1. 3DGS 的 “we densify every 100 iterations and remove any Gaussians that are essentially transparent” 已在第 5 页 PDF 原始文字项和 passage 中，但 passage 以跨栏残句逗号开头、以 `i.e., with` 结尾，被检索索引拒收；此前方法栏无法引用 prune。B070 只在明确句界裁去开头残句、裁去悬空解释尾巴，原始成员 quote 与锚点不改。方法重排序在同时存在增密、移除与渲染证据时给增密和移除各留一个步骤。未拼接断裂的 alpha 阈值。
2. MiMo 的 128 token 窗口和局部:全局 5:1 已在问题阶段 E001，不在新增的五条方法来源中；B069 方法提示虽然允许前序来源，却未明确要求写入定义机制的配置数值。B070 指示模型核对本轮和前序原文，写入关键参数并列入 `sources`。
3. 单个 E/S alias 对应多个原始 PDF 文字项。旧 UI 对一个 alias 逐项显示 `[7.1]…[7.12]`，真实页面视觉上过密。B070 每个出现位置只显示 `[7]`，使用原生 `details/summary` 展开所有可定位成员；同句重复 alias 只显示一次；识别模型输出的 `[E001]` 包裹，避免 `[[1]]`。未知 alias 保持普通文本，校验链不放宽。
