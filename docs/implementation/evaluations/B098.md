# B098：PDF滚轮／捏合缩放

用户确认范围为PDF区域内Ctrl/⌘＋滚轮、触控板捏合调整PDF大小；浏览器菜单/快捷键联动不在本批。

实现检查基于[MDN wheel事件](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)：触控板捏合发送ctrlKey wheel，取消默认行为使用非passive监听；普通wheel仍滚动。现代前端技能检索无直接对应指南，参考滚动回调轻量原则，现有滚动监听保留。

验证采用独立b098 Chromium、本机8766构建预览，存储模拟限定该origin；不访问pw-main或模型API。

实现：非passive局部wheel监听，像素/行/页delta归一化，RAF合并并串行应用，累积小于1%的细小变化；沿用25%–400%手动比例与全局偏好。指针附近页按比例锚定，过期尺寸异步更新被版本守卫拦截，切文档/卸载清理监听与未执行帧。

验证通过：
- 模拟Ctrl滚轮135%→165%，Meta滚轮回135%，20个微小捏合delta累积至146%；普通wheel和工具栏区域不拦截、不改PDF比例。
- Chromium原生鼠标/Control输入：PDF实际宽度612→746px，纵向页内指针比例误差0.000173；浏览器devicePixelRatio保持不变。
- 极大delta仍限制25%–400%，重新导入恢复25%手动偏好。
- 43文件/283测试、TypeScript、Chrome与Firefox构建和diff检查通过；回归覆盖忙时累积、反向缩放及监听清理。
- 实物触控板/不同操作系统未测试；捏合按浏览器ctrlKey wheel事件模拟验证。Firefox本批仅构建，无交互回归。
