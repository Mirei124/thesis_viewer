# B085 全局缩放缓存验收

2026-10-04，主 agent 使用独立 Chromium session b085、最终 Chrome 构建的 HTTP 预览与 browser.storage.local 持久模拟。自动概览关闭，未发模型请求。两个临时 PDF 内容 hash 不同；样本不入库。

| 场景 | 结果 |
|---|---|
| 无全局缓存 | 默认 auto，测试窗口显示 135% |
| 自定义 137% | 全局 manual scale 1.37；换另一 PDF 及刷新后重开均 137% |
| 旧文档记录 pageIndex 1、rotation 90、scale 4 | 恢复第 2 页、90 度，仍 137%；两页 renderKey 均 1.37:90 |
| 加减按钮 | 137%→162%→137%，全局值同步保存 |
| Fit page width／Fit page／Automatic zoom | 全局分别保存 fit-width／fit-page／auto，换 PDF 后模式保留，比例按页面与窗口重新计算 |
| 菜单 150%、resize 与旋转 | 全局仍 manual 1.5，显示 150% |
| 注入写失败并选择 200% | 本次阅读显示 200%，缓存仍前值 150%，无阻断 |
| 注入读失败后重开 | 回退 auto，显示 135%，阅读正常 |
| 恢复存储、选择 125%，URL fragment 打开第 2 页 | 显示 125%，页码 2，全局 manual 1.25 |

204 项测试通过，包括偏好合法／非法解析、写序列与跨打开读取、存储缺失／读写失败恢复。typecheck、双端构建及 git diff --check 通过。日志 `/tmp/b085-{tests,typecheck,chrome-build,firefox-build}.log`。浏览器脚本 `/tmp/b085-browser-check.js`、`/tmp/b085-browser-modes.js`。本批未做 Firefox 实际扩展交互；mock 用于偏好存储和 URL PDF 响应，PDF 渲染与阅读交互使用实际代码。
