## 2. 切分和来源实测

字符数是输入体积，**不是语义覆盖率**。放大参数的效果很有限，三篇方法输入完全未变；不能从“1500上限”推断实际有1500字符长的段落。

具体缺口：

- SAM：E002 image encoder与E003 prompt encoder可用，但decoder后续双向attention/动态分类器、loss和完整自动标注流程未充分进入方法包。
- Transformer：E003取自Conclusion、E004是FFN、E005是dropout、E006是不完整的encoder-decoder引导、E007是positional encoding。Q/K/V、masking与完整decoder机制漏选；章节标签存在正文被当标题的错误。
- Chinchilla：E003解释Approach 1，E004只有三种方法结论比较。Approach 2/3的具体拟合过程未提供。
- LoopVL：E005/E007为初始化/alignment，E006/E008为循环消融，E009为attention分析。L/H是什么、state怎样更新、mid-training与post-training没有在方法阶段覆盖。
- Video-MME：数据构造主干较好，评测输入/模态适用设置与评分不完整。3DGS：已有初始化/增密/渲染名称，但表示/监督/渲染内部解释不足。

段落可行性小试：SAM第5页与Transformer第4页先渲染检查，再以Poppler bbox-layout提取block。SAM的image encoder、prompt encoder、mask decoder、loss/training分别形成281、387、621、407字符block；Transformer有完整308字符attention定义和413字符multi-head解释。版面信息能恢复较好的段落单元，但这些block不是自动正确阅读顺序：SAM双栏末尾接右栏起始，Transformer公式和正文跨block。该试验只验证可用信号，不宣称生产段落功能已实现。

B组的文字更长，缺口却仍在，证据优先于提示词修辞。C组证明完整原文能支撑解释；同时它容易扩写整段输入，包括结果、数据统计与次要配置。D组更接近用户要的“完整复述机制、简化枝节”，但人工方法范围、残余事实错误及不同输出上限使其仍是研究原型。

36份有效结果均为stop，列出的sources均属于已发送alias。**这仅是格式/编号检查通过**，上表中的错误正说明不能据此声称全部回答正确。

## 5. 合并贡献与创新

SAM、Chinchilla、Video-MME分别以相同整章来源做split与merged，均要求400–600中文字，temperature=0，max_tokens=12000。它们使用相关方法章而非全文所有实验/Related Work，观察范围仅为组织质量。

- SAM：split实际扩展到两栏共14条，存在数据引擎、任务泛化的分散重复；merged收敛到4项，能在promptable task后直接解释与interactive/multi-task的差别。
- Chinchilla：split把scaling指数与Kaplan差别拆开；merged放在同一项，更好回答“改变了什么”。但merged前两项仍有缩放结论重复，合栏不自动去重。
- Video-MME：merged第一项明确比较只针对multiple-choice子集，比较边界更近；第四项把certificate length结论限定为EgoSchema的措辞仍过强，需要原文复核，不应照收。

建议合并显示，保留论断层次的证据类型；无需强制每项贡献都必须有创新比较。样本只有三篇、非盲评、每组单次，结论是推荐方向而非统计优势。
