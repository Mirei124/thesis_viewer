# B113 阅读工具栏与标注验收

2026-11-01。实现范围与逐项结果见[批次](../batches/B113.md)。

## 已实现

初选时隐藏颜色和字符计数，统一翻译、选区提问、高亮按钮；编辑已有标注时再显示颜色/背景高亮或下划线。翻译主标题右侧为复制、关闭SVG图标，去“已扩展至…”及重复翻译标题，不改句子扩展、请求/缓存或取消逻辑。

StoredPdfHighlight增加可选style，旧缺失/未知遗留值按highlight显示，备份仅接受缺失/highlight/underline。数据库和备份版本均不变，新下划线以PDF原矩形锚点投影、根据用户旋转选择底/左/上/右边线，不改PDF文字层或复制内容。
