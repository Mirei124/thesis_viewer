# B103 验收与边界

日期：2026-10-31。

## 实现
- 作者：XMP dc:creator → Info.Author → 首页显著标题下、摘要前的作者区域。保留倒置姓名，限制异常字段长度和人数。
- 机构：同一区域的机构特征行，按布局重组、去重；不猜作者对应哪个机构。
- 历史：可选 authors/institutions 与来源，旧库无破坏迁移。重新打开补充；同内容失败保留已有结果，内容 hash 变化不沿用旧作者机构。
- 标题／作者／机构／URL 均可搜索，首页和侧栏共用列表。机构／作者未知时省略，不显示猜测值。
- 本地解析不调用模型、不增加权限，不保存 PDF 字节；无法自动补齐未重新打开的旧历史。

## 限制及会议发表信息调查
首页提取是启发式，匿名／扫描 PDF、特殊封面、非常规标题字体、未知企业名称、复杂混合排版可能漏提或有误，当前不提供人工编辑。不对所有 PDF 保证完整，也未在 Firefox 真实扩展交互复测。

会议信息未实现自动查询。可靠性建议顺序：DOI 对应正式书目记录、arXiv ID 的 journal_ref／DOI／comments，再辅以首页明确的出版或录用声明。Crossref 的 conference 数据可包括 event 与 proceedings 元数据；arXiv 的 published 是上架日期，不能等同会议发表。参考官方文档：
- https://www.crossref.org/documentation/schema-library/markup-guide-record-types/conference-proceedings/
- https://www.crossref.org/documentation/retrieve-metadata/rest-api/
- https://github.com/arXiv/arxiv-docs/blob/develop/source/help/api/user-manual.md

正文／参考文献出现 CVPR 不构成发表证据；Submitted to／under review 不等于 Accepted；未知不等于未发表。未来查询应保存来源／状态，优先 ID 匹配，标题搜索需核对作者，缺少结果不作否定结论。本批不增加任何外部书目查询。
