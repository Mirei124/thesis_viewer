## method

本文的贡献类型是同时提出 task、model 与 data 三者的组合：先定义一个 promptable segmentation task，用它在广泛数据上预训练一个可提示的模型，再通过 prompt engineering 把同一模型迁移到多种下游分割问题 [E197][E198]。任务的输入是图像与一个 prompt，prompt 可以是前景/背景点、粗略的 box 或 mask、自由文本，或任何指示要分割图像中什么对象的信息；输出是一个 valid mask，即使 prompt 有歧义（例如衬衫上的一点可能指衬衫或穿衣的人），也要求给出至少对应其中一个合理对象的 mask [E201][E214]。该任务既充当预训练目标，也充当零样本迁移的手段：下游任务被改写为对模型的提示 [E215][E216]。作者明确指出这种可组合设计不同于以往固定的 multi-task segmentation 系统 [E220]。

模型即 Segment Anything Model (SAM)，由三部分组成：heavyweight 的 image encoder、灵活的 prompt encoder，以及轻量的 mask decoder；重编码器每张图只跑一次，其 image embedding 可被不同 prompt 复用并按摊薄成本查询，从而以实时速度产出 mask，并对歧义 prompt 输出多个 valid mask 及相应置信度 [E202][E226]。image encoder 采用 MAE 预训练的 Vision Transformer (ViT)，即 ViT-H/16，使用 14×14 windowed attention 与四个等间隔的 global attention block；1024×1024 的输入被编码为 16× 下采样的 image embedding（64×64），再经 1×1 与 3×3 卷积压到 256 通道 [E230][E297]。由于该编码只做一次、不随 prompt 重复，prompt 侧可以负担很低的延迟 [E297][E234]。

prompt encoder 区分稀疏与稠密两类提示：点用位置编码加上表示前景或背景的 learned embedding 表示，box 用左上角与右下角两对“位置编码＋类型嵌入”表示，自由文本用 CLIP 的 text encoder 编码，三者都映射为 256 维向量 [E231][E298]。稠密提示即 mask，先按低于输入 4× 的分辨率输入，再用两个 stride-2 卷积继续降采样，最后用 1×1 卷积对齐到 256 通道并与 image embedding 逐元素相加；没有 mask 提示时，改用表示 no mask 的 learned embedding [E299][E308]。mask decoder 负责把 image embedding、prompt embeddings 与一个 output token 映射为 mask [E232]。它由两层修改过的 Transformer decoder block 组成，每层依次执行四步：token 之间的 self-attention、token 作为 query 对 image embedding 的 cross-attention、逐 token 的 MLP、以及 image embedding 作为 query 反向对 token 的 cross-attention，最后一步用提示信息更新 image embedding [E310][E312]。为保留几何信息，image embedding 每次参与 attention 时都会重新加上位置编码，原始 prompt token（含其位置编码）也会被重新加回 [E313]。解码后 image embedding 经转置卷积上采样 4×，output token 通过一个小型 MLP 输出与上采样 embedding 通道数相同的向量，二者逐点相乘得到 mask [E314][E316]。

针对 prompt 歧义，SAM 对单个 prompt 同时预测多个 mask，默认 3 个（对应整体、部分、子部分这类嵌套情形），训练时只对损失最小的那个 mask 回传梯度，并用额外的 output token 预测 IoU 作为 mask 的置信度排序依据 [E233][E319]。当提供多个 prompt 时歧义大幅减少，模型改为只输出一个 mask，由第四个 output token 承担，该第四个 mask 在单 prompt 时不会被返回 [E320]。mask 预测由 focal loss 与 dice loss 的线性组合监督（比例 20:1），IoU 预测头用与真实 IoU 之间的 mean-square-error 训练并以常数 1.0 计入总损失 [E235][E321]。训练模拟交互式分割：先以相等概率随机取一个前景点或目标 mask 的 bounding box 作为首个 prompt（box 坐标加入标准差为边长 10%、最多 20 像素的噪声），之后每一步从上一轮预测与真值的误差区域均匀采样新点，假阴性处取前景点、假阳性处取背景点，并把上一轮未阈值化的 mask logits 作为额外提示回喂 [E322][E323]。迭代采样 8 个点后收益递减，另加两次不采样新点、只让模型自行细化的迭代，共 11 轮；轻量 decoder 使这种多轮训练开销很小 [E324]。优化使用 AdamW 与线性 warmup，warmup 后初始学习率 8e-4，训练 90k 迭代（约 2 个 SA-1B epoch），batch size 256，并采用 weight decay、drop path 与 layer-wise learning rate decay，不使用数据增强，从 MAE 预训练的 ViT-H 初始化 [E325][E329]。推理时预计算 image embedding 即可复用，prompt encoder 与 mask decoder 在浏览器 CPU 上约 50ms 内给出 mask [E202][E234]。

数据侧的核心贡献是 data engine：由于互联网上没有现成的大规模 mask 数据，作者让模型与数据采集互相迭代，分三个阶段 [E200][E237]。assisted-manual 阶段用浏览器内的交互式分割工具，标注员点击前景/背景点并用像素级 brush 与 eraser 修正，借助预计算 embedding 获得实时模型反馈；该阶段不施加语义约束，stuff 与 things 都可标注，按显著度进行，单个 mask 超过 30 秒即切到下一张；模型从公开分割数据集起步，随新数据累积重训共 6 次，image encoder 从 ViT-B 扩到 ViT-H，单 mask 平均标注时间由 34 秒降到 14 秒，每图 mask 数由 20 升至 44，该阶段从 120k 图像得到 4.3M masks [E238][E240]。semi-automatic 阶段先用第一阶段 mask 训练一个采用通用 object 类别的 bounding box detector，用它预填高置信 mask，让标注员专注补充未标注对象以提升 mask 多样性；该阶段新增 5.9M masks、180k 图像（合计 10.2M），期间重训 5 次，单 mask 标注时间回升到 34 秒，每图 mask 数（含自动 mask）从 44 升到 72 [E240]。fully automatic 阶段无需标注员：此时模型已具备歧义感知能力，作者用 32×32 的规则点网格作为 prompt，每个点输出一组可能对应有效对象的 mask，落在部分或子部分上的点会同时返回子部分、部分与整体 [E240]。随后用模型的 IoU 预测模块挑选高置信 mask，只保留稳定 mask（把概率图在 0.5±δ 处阈值化后得到相似结果的 mask 视为稳定），再用 non-maximal suppression (NMS) 去重，并额外处理多个重叠的放大裁剪以改善小目标质量 [E240][E241]。该流程跑遍全部 11M 图像，产出 1.1B 个高质量 mask，即 SA-1B [E242][E204]。

SA-1B 包含 11M 张有授权且保护隐私的图像与 1.1B 个 mask，其中 99.1% 来自上述全自动阶段，因此数据集只纳入自动生成的 mask [E245][E246]。图像平均分辨率 3300×4950，发布时最短边下采样到 1500 像素，人脸与车牌已做模糊处理 [E246]。质量验证上，从随机 500 张图像（约 50k mask）出发，由专业标注员用 brush 与 eraser 修正并与自动 mask 配对，94% 的配对 IoU 超过 90% [E247]。除几何提示外，prompt encoder 也支持自由文本：训练时用 CLIP 计算文本与图像 embedding（训练用 mask 取自 data engine 前两阶段），把每个 mask 的 bounding box 随机扩展 1×–2×、保持长宽比方形裁剪并缩放到 336×336，以 50% 概率抹去 mask 之外的像素，并在最后一层用 masked attention 把输出 token 的注意力限制在 mask 内部，其 output token embedding 作为提示，随后再叠加迭代点提示进行细化 [E398][E403]。推理时直接使用未改动的 CLIP text encoder 产生提示，依赖 CLIP 已对齐的文本与图像 embedding 空间 [E406]。
