## method

本文的 Transformer 处理 sequence transduction：encoder 把输入符号表示序列 (x1,…,xn) 映射为连续表示序列 z=(z1,…,zn)，decoder 以 z 为条件逐个生成输出符号 (y1,…,ym)，每步把先前生成的符号作为额外输入，因此是 auto-regressive 的 (E045)。与以往主要靠 attention mechanism 连接 encoder 与 decoder 的模型不同，该架构完全基于 attention，不含 recurrence 与 convolution (E026)。作者的出发点是当时主流的 recurrent neural networks、long short-term memory 与 gated recurrent 网络按符号位置沿计算时间展开，顺序性使训练样本内部无法并行 (E035, E036)。整体上 encoder 与 decoder 都由 stacked self-attention 与 point-wise、fully connected 层构成 (E048)。

Encoder 由 N=6 个相同层堆叠，每层含两个子层：先是 multi-head self-attention，再是 position-wise fully connected feed-forward network；每个子层外包 residual connection 并接 layer normalization，即输出为 LayerNorm(x + Sublayer(x))，Sublayer(x) 是子层自身实现的函数；为使残差可加，所有子层与 embedding 层的输出维度统一为 d_model=512 (E050)。Decoder 也堆叠 N=6 个相同层，并插入第三个子层，对 encoder 栈的输出做 multi-head attention；decoder 的 self-attention 被改成遮蔽式，阻止某个位置关注其后的位置，配合输出 embedding 相对输入偏移一个位置，使位置 i 的预测只依赖小于 i 的已知输出 (E051)。

Attention 函数把 query 与一组 key-value pairs 映射为输出，四者都是向量，输出是 value 的加权和，每个 value 的权重由 query 与对应 key 的 compatibility function 算出 (E053, E058)。本文使用 Scaled Dot-Product Attention：query 与 key 的维度为 d_k、value 的维度为 d_v，先求 query 与所有 key 的 dot product，各自除以 √d_k，再经 softmax 得到 value 上的权重 (E060)。实现时把一组 query、key、value 打包成矩阵 Q、K、V，输出矩阵为 Attention(Q,K,V)=softmax(QK^T/√d_k)V，其中 QK^T 是 query 与所有 key 的成对 dot product 组成的矩阵，softmax 给出 value 上的权重后再与 V 相乘 (E061, E064)。缩放并非装饰：d_k 较大时 dot product 幅值变大，会把 softmax 推入梯度极小的区域，故乘 1/√d_k 抵消 (E071, E073)。作者给出的量纲解释是，若 q 与 k 的各个分量是均值 0、方差 1 的独立随机变量，其 dot product 均值为 0、方差为 d_k (E078, E080)。与用单隐层前馈网络计算 compatibility 的 additive attention 相比，dot-product attention 理论复杂度相近，但实践中更快、更省空间，因为它能用高度优化的矩阵乘法代码实现 (E066, E070)。

Multi-Head Attention 不直接用 d_model 维的 query、key、value 做一次 attention，而是用 h 组不同的、可学习的线性投影把它们分别映到 d_k、d_k、d_v 维，在每组投影版本上并行执行 attention 得到 d_v 维输出，再把这些输出拼接并做一次投影得到最终结果 (E076, E083)。其形式为 MultiHead(Q,K,V)=Concat(head1,…,headh)W^O，其中 head_i=Attention(QW_i^Q, KW_i^K, VW_i^V) (E086, E088)；投影矩阵 W_i^Q、W_i^K ∈ R^{d_model×d_k}、W_i^V ∈ R^{d_model×d_v}、W^O ∈ R^{hd_v×d_model} 都是可学习参数 (E091, E092)。这样设计是因为单个 head 的加权平均会抑制模型同时关注不同位置的不同表示子空间；本文取 h=8、d_k=d_v=d_model/h=64，因此总计算量与全维度的 single-head attention 相近 (E084, E094)。

Multi-head attention 在模型中有三种用法 (E096)。encoder-decoder attention 层的 query 来自上一层 decoder，key 与 value 来自 encoder 的输出，使 decoder 每个位置都能关注输入序列的所有位置 (E097)。encoder 的 self-attention 层中 query、key、value 同源，都取自上一层 encoder 的输出，每个位置可关注上一层所有位置 (E098)。decoder 的 self-attention 让每个位置只关注该位置及之前的位置，为保持 auto-regressive 性质、阻断向左的信息流，实现上在 scaled dot-product attention 内把 softmax 输入中对应非法连接的值置为 −∞ (E099)。

每个 encoder 与 decoder 层在 attention 子层之外还有 position-wise feed-forward network，对各位置单独且同样地施加，由两个线性变换与中间的 ReLU 组成：FFN(x)=max(0, xW1+b1)W2+b2 (E101, E102)。线性变换在各位置之间相同、在层与层之间不同，也可看成两个 kernel size 为 1 的卷积；输入输出维度 d_model=512，内层维度 d_ff=2048 (E103)。

输入与输出 token 由可学习 embedding 转成 d_model 维向量，decoder 输出再经可学习的线性变换与 softmax 得到下一 token 的概率；两个 embedding 层与 pre-softmax 线性变换共享同一权重矩阵，embedding 层中这些权重乘以 √d_model (E105)。由于模型既无 recurrence 也无 convolution，位置信息必须显式注入：把 positional encoding 加到 encoder 与 decoder 栈底的输入 embedding 上，二者同为 d_model 维故可直接相加 (E117)。本文使用不同频率的正弦与余弦函数：PE(pos,2i)=sin(pos/10000^{2i/d_model})，PE(pos,2i+1)=cos(pos/10000^{2i/d_model})，其中 pos 是位置、i 是维度 (E120, E122)。每个维度对应一条正弦曲线，波长从 2π 到 10000·2π 构成几何级数 (E124)。作者选择该函数，是假设它便于模型学习按相对位置的 attention，因为对任意固定偏移 k，PE_{pos+k} 可表示为 PE_pos 的线性函数；作者也试过 learned positional embedding，得到几乎相同的结果，最终选正弦版本是期望它能外推到比训练时更长的序列 (E125, E126)。

训练阶段，English-German 使用约 450 万句对的 WMT 2014 数据集，以 byte-pair encoding 编码，源与目标共享约 37000 token 的词表；English-French 使用 36M 句对的 WMT 2014 数据集并切成 32000 的 word-piece 词表；句对按近似序列长度分批，每批约含 25000 个 source tokens 与 25000 个 target tokens (E143)。优化器为 Adam，β1=0.9、β2=0.98、ε=10^−9 (E148)。学习率按 lrate = d_model^{−0.5}·min(step_num^{−0.5}, step_num·warmup_steps^{−1.5}) 变化，即前 warmup_steps 步线性上升、之后按步数平方根的倒数下降，warmup_steps=4000 (E151, E152)。residual dropout 施加在每个子层输出被加回子层输入并归一化之前，也施加在 encoder 与 decoder 中 embedding 与 positional encoding 之和上，base 模型取 P_drop=0.1 (E177, E178)。label smoothing 取 ε_ls=0.1，它使模型学得更不确定、perplexity 变差，但提升 accuracy 与 BLEU (E179)。作者称训练中共用三类正则化，本批摘录只完整给出上述两项 (E154)。

推理仍按 auto-regressive 逐词生成；翻译任务使用 beam search，beam size 为 4、length penalty α=0.6 (E189)；base 模型取最后 5 个、big 模型取最后 20 个 checkpoint 平均 (E188)。
