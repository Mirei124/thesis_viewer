## method

本文属于模型/算法类工作，核心贡献是提出 LoRA（Low-Rank Adaptation）这一参数高效适配机制，而不是数据集或评测基准，因此方法范围以该机制本身及必要的训练、推理流程为主（E147、E169）。任务设定上，给定以 Φ 参数化的预训练自回归语言模型 P_Φ(y|x)，例如基于 Transformer 架构的 GPT 类模型，目标是把它适配到 summarization、machine reading comprehension (MRC)、natural language to SQL (NL2SQL) 等下游条件文本生成任务；每个下游任务由 context-target 对集合 Z = {(x_i, y_i)} 表示，x_i 与 y_i 都是 token 序列（E180）。输入是预训练权重与任务的 context-target 训练集，输出是适配后的任务条件模型。

全量 fine-tuning 把模型从预训练权重 Φ_0 更新为 Φ_0 + ∆Φ，以式(1) max_Φ Σ_{(x,y)∈Z} Σ_{t=1}^{|y|} log P_Φ(y_t | x, y_<t) 为目标反复沿梯度更新（E182、E184）；其代价在于每个下游任务都要学一份维度 |∆Φ| 等于 |Φ_0| 的参数增量，预训练模型很大（如 |Φ_0| ≈ 175B 的 GPT-3）时，存储与部署多份独立实例很难做到（E187）。论文改为把任务相关增量重新参数化为 ∆Φ = ∆Φ(Θ)，用远小于 |Φ_0| 的参数集合 Θ 来编码，把寻找 ∆Φ 的问题变成对 Θ 的优化：max_Θ Σ_{(x,y)∈Z} Σ_{t=1}^{|y|} log p_{Φ_0+∆Φ(Θ)}(y_t | x, y_<t)（式 2），在 GPT-3 175B 上 |Θ| 可小至 |Φ_0| 的 0.01%（E188、E190、E195）。

低秩参数化的具体做法针对稠密层：这类层执行矩阵乘法，其权重矩阵通常是 full-rank；受预训练语言模型存在低 intrinsic dimension 的观察启发，论文假设适配过程中权重的更新同样具有低 intrinsic rank（E216）。于是对维度 d×k 的预训练权重矩阵 W_0，把更新约束为低秩分解 W_0 + ∆W = W_0 + BA，其中 B ∈ R^{d×r}、A ∈ R^{r×k}，秩满足 r << min(d,k)（E218、E220）。这里可训练的 A 把 k 维输入投影到 r 维低秩子空间，B 再把结果映射回 d 维输出空间，因此乘积 BA 只用 r 个方向就承载了原本需要完整 d×k 自由度表达的更新 ∆W，这正是低 intrinsic rank 假设的可参数化形式。训练时 W_0 被冻结、不接收梯度，只有 A、B 含可训练参数；同一输入同时送入 W_0 与 ∆W = BA，两路输出向量按坐标逐元素相加，前向传播为 h = W_0x + ∆Wx = W_0x + BAx（式 3）（E221、E222）。初始化上，A 采用随机高斯初始化、B 置零，因此训练起点处 ∆W = BA 为零；训练中再把 ∆Wx 乘上 α/r，其中 α 是不随 r 变化的常数（E223、E225）。用 Adam 优化时，只要初始化缩放得当，调 α 与调学习率大致等价，论文因此把 α 设为第一次尝试的 r 且不再调参，使改变 r 时不必重新调超参数（E227）。

论文沿用 Transformer 的维度约定：d_model 是层的输入输出维度，W_q、W_k、W_v、W_o 是自注意力模块中的 query/key/value/output 投影矩阵，W 或 W_0 指预训练权重矩阵，∆W 是适配期间累积的梯度更新，r 是 LoRA 模块的秩（E176、E177）。原则上 LoRA 可施加于任意权重子集；论文聚焦自注意力模块的四个权重矩阵，把 W_q（或 W_k、W_v）视为 d_model × d_model 的单一矩阵，即便其输出维度通常被切分到多个 attention head，并冻结 MLP 模块（E246）。多数实验中只适配 W_q 与 W_v，此时可训练参数数为 |Θ| = 2 × L̂ × d_model × r，其中 L̂ 是施加 LoRA 的权重矩阵个数（E299）。

推理阶段与训练阶段不同：部署时可显式算出并存储 W = W_0 + BA 后照常推理，因为 W_0 与 BA 同为 d×k 矩阵；切换到另一个下游任务时，先从 W 减去 BA 再加回另一组 B'A'，操作很快、内存开销很小，因此按构造不引入相对微调模型的额外推理延迟（E233、E235、E238、E244）。其局限是，若已把 A、B 合并进 W，就难以在同一个前向批次中混合使用不同 A、B 的任务样本；若不合并权重，则可动态选择样本对应的 LoRA 模块（E252）。效率与部署上，由于绝大多数参数不需要保存梯度与优化器状态，在 r << d_model 时 VRAM 需求最多降到约 2/3，GPT-3 175B 的训练显存由 1.2TB 降到 350GB；取 r = 4 且只适配 query/value 投影时 checkpoint 由 350GB 降到约 35MB，并可通过只替换 LoRA 权重在部署中切换任务（E247、E249）。与全量 fine-tuning 的关系上，若对所有权重矩阵施加 LoRA 并训练所有 bias，再把 r 设为预训练权重矩阵的秩，可大致恢复全量 fine-tuning 的表达能力；随可训练参数增加，LoRA 的训练大致收敛到训练原模型，而 adapter 类方法收敛到 MLP、prefix 类方法收敛到无法处理长输入序列的模型（E230、E232）。

论文还用实验检验了低秩假设：在 18M 可训练参数预算（FP16 下约 35MB）下，适配单种注意力权重对应 r = 8、适配两种对应 r = 4（均覆盖全部 96 层），结果显示同时适配 W_q 与 W_v 整体最佳，而把参数集中在 ∆W_q 或 ∆W_k 上明显更差（E353、E357、E358）；对 {W_q, W_v} 而言 r 小到 1 已足够，单独训练 W_q 则需要更大的 r（E364）。为判断更新矩阵是否真的 rank-deficient，论文对学到的适配矩阵做 singular value decomposition，并用基于 Grassmann distance 的归一化子空间相似度 φ 度量不同秩设置下顶部奇异方向子空间的重叠（φ 取值在 [0,1]，越大表示重叠越多）；结果显示 A_{r=8} 与 A_{r=64} 的顶部奇异方向显著重叠，其余方向则不然（E372、E380、E389、E398、E401）。
