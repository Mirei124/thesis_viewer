# B083 自动生成设置浏览器验收

日期：2026-10-04。主 agent 使用独立 Chromium、最终 Chrome MV3 构建的本机 HTTP 预览及测试用扩展 storage／permissions API。模型接口由 Playwright route 模拟，使用实际请求中的合法 source aliases，经应用正常 JSON／证据定位校验。测试使用 Video-MME.pdf，HTTPS PDF 下载响应也由本地该文件模拟；没有外发真实模型请求。

- 两个 checkbox 默认 false；未开启时导入 PDF，模型请求列表为空。
- 设置页勾选两项并保存，偏好为 threeLine=true／detailed=true。API 权限 request 使用 http://127.0.0.1/*，当时 navigator.userActivation.isActive=true；打开 PDF 后无新权限 request，生成三行及详细六栏目，请求顺序为 three-line、problem_motivation、method、contributions、relative_novelty、experiments_ablations、limitations，前两条在前一响应完成前均已启动。
- 两类已验证结果缓存后重载并打开同 PDF，两类恢复、请求数零。
- 清空缓存，仅启用三行，自动请求只有 three-line。随后在同 reader 的 storage 更新为仅详细，再打开同 PDF，偏好重新读取，自动完成六个详细栏目，无三行请求。
- 仅详细自动启动时立即取消，只有第一栏目请求，等待后未追加后续栏目或自动重启，无详细结果。
- 清空缓存、启用两项但模拟已撤销 API 权限：模型请求和新授权 request 都为空，两类显示可检查模型／权限并手动生成。设置页继续保存后两项均关闭，明确显示自动概览关闭的原因。
- 模拟三行返回无效内容：只自动请求一次，等待后没有重试；恢复有效模拟响应再手动生成，成功显示三条。
- HTTPS PDF URL 导入在仅三行开启时自动请求一次；唯一权限 request 是用户点击导入时的 PDF host https://pdf.test/*，自动模型请求无新权限申请。
- 中文深色 375×812 设置页，两个标签“自动生成三行概览”“自动生成详细概览”正常且可分别选择，页面无横向溢出；截图 /tmp/b083-settings.png 已由主 agent 目视检查。英文标签及保存状态在上述流程核查。

子 agent 全套 34 文件／197 项测试通过；主 agent 最终 typecheck、Chrome／Firefox 构建和 diff 检查通过。临时脚本位于 /tmp/b083-init.js、b083-lifecycle.js、b083-url-and-settings.js、b083-failure.js，长期证据以本文件为准。

边界：permissions API 为注入模拟，不能替代本批 Chrome／Firefox 真实扩展授权弹窗测试；未调用真实模型，不代表服务商限流或模型质量重测。构建保留已有大 chunk 警告。
