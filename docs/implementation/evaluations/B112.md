# B112 概览上下文优化与真实对照

2026-11-01。先实验后接入，基线为`44d60de`（0.2.0）。本批没有新增向量API或图像输入，附录继续排除。

## 实验与门槛

四篇公开原始PDF：SAM（分割模型/数据引擎）、Attention Is All You Need（架构）、Video-MME（多模态基准）、Chinchilla（计算缩放实证）。[论文版本/字节哈希](B112/papers.json)固定，提取使用生产PDF.js/锚点/章节代码，未人工修剪单篇输入或按论文身份加规则。

使用用户已配置环境中的deepseek-flash，兼容API，temperature=0，structured output开启，semanticReview关闭，contextLimit=128000、outputLimit=32000（沿用概览的总窗口预算契约，不改问答的128K/64K独立上限）。thinking未指定，沿用服务商默认；完成token包含服务商计入的推理用量。每轮至多3并发、每种方案每篇三行1次+五栏5次。

共72次真实有效响应：原基线24次、第一候选24次、修正后的最终候选24次，无格式修复额外调用。原始输入/响应存在忽略的`.local-cache/batches/B112/`，不记录Authorization或密钥；[评测输出](B112/evaluated-answers.json)保留三轮实际文字，未删除失败候选。

质量审查先冻结[机制/贡献清单](B112/review-rubric.json)，随后随机文件名匿名对照，由一个独立agent按PDF原文和实际引用成员审核。这是小样本、单评审者的agent盲审，不是人工金标准、独立多评审共识或统计显著性结论。

## 拒绝的首轮

[首轮审查](B112/blind-review.json)发现Chinchilla三行把一种方法的内部步骤误分为另一种，遗漏IsoFLOP；共享完整引言给全部栏目还让输入上涨。因此未上线首轮候选。通用修正为：识别没有Abstract标题的首页研究摘要，排除caption续段，不从局部来源补造完整方法枚举；完整引言仅供问题/方法/贡献复用，实验/局限保留原有选材，不无条件加引言。无论文身份硬编码。

最终轮在每篇第一条来源消息开头加固定本轮nonce，阻断首轮原文前缀预热；同论文各栏仍复用相同nonce，系统提示仍可按服务商正常缓存。该评测nonce不进入产品。基线是首次来源请求，不重新用热缓存夸大节省。缓存状态仍不是完全可控实验变量。

## 最终质量结果

[最终盲审](B112/blind-final-review.json)按每篇归一再平均，P为最终候选，Q为基线（匿名顺序随机）。

| 指标 | 基线 | 最终候选 |
|---|---:|---:|
| 三行核心贡献覆盖 | 76.04% | 89.58% |
| 三行互补性（1–5） | 3.75 | 5.00 |
| 方法核心机制覆盖 | 85.24% | 89.58% |
| 方法可复述性（1–5） | 4.00 | 4.25 |
| 新增重大事实错误 | — | 0 |

覆盖是冻结清单上的0缺失/1提及/2解释评分，不代表通用准确率。不是每篇都提升：SAM三行省去了直接零样本验证；Chinchilla方法补齐等预算验证但schedule解释略少，总覆盖持平。Video-MME对三模态协议的“每次”表述仍过于绝对，未充分限定音频支持模型。SAM实验人工评分结论可由原文支持，但其选择的引用更直接支持AR，仍有引用蕴含问题。Attention局限不再排他地说“仅WMT”，但该栏也不能当作全部实验覆盖总结。

## 实际token用量

来源为服务商返回的计数，包含相应类别全部首次请求，见[逐篇逐轮用量](B112/final-usage-summary.json)。

| 指标 | 基线 | 最终候选 | 变化 |
|---|---:|---:|---:|
| 三行输入 | 7,507 | 7,905 | +5.3% |
| 三行完成（含推理） | 10,514 | 5,433 | −48.3% |
| 详细输入 | 92,492 | 85,026 | −8.1% |

三行是以少量输入增长换取完整证据和要点覆盖，不宣传普遍减少输入；完成用量受推理与随机性影响，单轮不能承诺稳定减半。缓存命中减少未命中计费量，不等于输入token消失。未套用服务商价格，因此不声称金额降幅；未将API用时当作可复现端到端性能提升。

## 产品接入及验证

- 三行：`threeLineContext.ts`保留完整段落及私有source映射，紧凑payload；生成/验证/缓存恢复统一expanded ledger。短中文或段落选择失败有明确标记的旧摘录回退，不能冒充完整段落；normal及fallback共用附录/参考父链和明确标题边界，首页直接以Appendix A开头也排除。
- 详细：默认`detailedOverviewShared.ts`使用纯原文前缀，不把旧模型回答当证据；方法按输入、机制、连接与训练/使用组织。超预算、映射缺失或启用语义复核时，在任何模型调用前退回原独立完整分批路径。格式错误仍最多一次修复，来源错误不额外付费重试。
- 三行v9、详细v21令旧上下文缓存自然失效，不删除历史/问答/标注。
- [生产与实测一致性](B112/production-equivalence.json)：4篇三行+20个详细栏目的选材/指令除版本、策略标记及评测nonce外完全一致；四篇录制真实回答全部通过生产来源校验、三行与详细缓存校验。
- 独立实际Chromium扩展，SAM原始30页PDF，回放已实测响应而非再次付费调用：三行和五栏成功、无错误，三核心栏原文前缀一致；整段26个成员的末尾可从引用浮窗跳至PDF第2页。重新选同一PDF后两类结果恢复、0模型请求、38个来源按钮可用。[缓存恢复截图](B112/production-cache-restored.png)。此项验证UI与资源绑定，不冒充额外真实模型试验。
- 类型检查、53文件／414测试、Chrome/Firefox构建和diffcheck通过。Firefox实际运行、100K级输入压力、更多语言/论文类型和多轮重复统计尚未覆盖。
