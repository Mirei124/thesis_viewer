1. SAM 方法阶段：至少提供能共同支撑 image encoder、prompt encoder、mask decoder 输入／输出关系的原文，且数据引擎仍有可引用来源；若五条限制不可同时覆盖，记录具体取舍。

3. Video-MME 方法阶段：视频采集、三题/视频标注、独立标注者复核、语言清楚与答案逻辑检查、纯文本可答性筛除有足够原文；不得以 Discussions 的长视频瓶颈代替数据构造。
4. 3DGS 方法阶段：SfM 初始化、各向异性表示、clone/split/prune、tile rasterizer 至少保留 B068 的覆盖；不引入补充材料或无关引言抢占主线。
5. 每条 alias 可回到当前 PDF 的原始成员；未知 alias 拒绝、预算、阶段顺序、去重与局部安全降级保持。调用结果不得依赖新网络服务。

## 第五篇样本与浏览器恢复

Scaling Laws for Encoder-Free Multimodal Pretraining*。PDF 已保存为 `/tmp/B069-2609.35457.pdf`，纳入本批静态与真实模型验收。`pw-main` 在沙盒外可通过 `playwright-cli -s=pw-main` 操作；扩展已由用户重新加载，阅读页已有该文的旧版概览。Moonlight 页面为 `https://www.themoonlight.io/paper/313461d2-35ce-43a9-8d90-e2ce869c179b`。

Moonlight 对照重点：11 个匹配的稀疏 MoE 解码器阶梯，IsoFLOP 的模型算力／训练 token 最优分配与损失前沿拟合，encoder-free 与 encoder-based 的算力／模型效率比较；多模态模型分配指数 0.570 对 0.464、约 10^22 FLOPs 的预测交叉，以及视觉 token 双向注意力、浅层隐式视觉编码、专家路由集中三项机制。当前扩展的旧版详细概览首栏输出“newSources 与 legalSourceAliases 均为空”，而其他栏基本有内容；实验／局限栏误称一些数值“被截断”。新构建后需区分输入缺证与模型偶发错误，并检查上述事实是否进入对应栏目的实际 packet。
