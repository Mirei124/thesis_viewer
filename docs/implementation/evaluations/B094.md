# B094：完整章节详细概览生产评测

日期：2026-10-09。模型：用户指定 deepseek-flash。详细方案见[08](../../planning/08-detailed-overview-quality.md)，手选章节方向实验见[B090](B090.md)。本批使用真实 PDF.js 提取、生产段落/章节选择、预算与生成 runner；没有以人工章节摘录替代产品输入。

## 已实现行为

- 从几何行、双栏阅读顺序重建自然段，识别章节树，保留每个原始 PDF item 的文字与坐标；不再按520/1500字符裁出方法碎片。跨页/栏不确定时分开保留。
- 详细证据账本补回可验证附录，三行沿用原账本。输入含完整引言、方法、实验与未知正文，以及必要或显式引用附录。ResNet的bottleneck位于实验章，实测后恢复方法的完整实验正文覆盖，由提示控制输出范围。
- contextLimit作为输入与输出的总窗口；保守估计加安全余量，按剩余容量调整实际输出额度。超限按段落/原始成员边界分批，保留后部；不可拆单成员超限明确失败。方法保留合理推理/输出空间。
- 五栏合并贡献与相对创新，支持论断级来源与claimKind。方法面向未读者，要求模块定义、输入/变换/输出/连接及训练与推理区别；完整上下文不意味着逐段复述。v17增加方法初稿对照相同原文复核。
- 每批引用验证、全局展示alias、取消隔离、失败保留其他栏目；不完整结果不缓存。旧六栏缓存失效。低预算分批按原文顺序合并，尚不是一次全局重新综合，可能重复，界面诊断明确说明。

## 样本与实验边界

八篇：SAM、3D Gaussian Splatting、Transformer、Chinchilla、Video-MME、LoopVL、ResNet、LoRA，覆盖分割、图形、序列架构、缩放规律、评测集、视频多模态及参数高效训练。

八篇结构回放均0无效原文成员、0可靠原始块遗漏；这不证明章节语义分类完全正确。部分图中标签仍可能成为标题，公式保留字符但不保证排版复原，跨栏断字尚存。结构证据在[structure](B094/structure/summary.json)。该结构快照选材统计早于恢复实验章，最终模型输入以每篇request为准。

真实API配置contextLimit=128000、outputLimit=32000，无手填论文专属范围。首轮八篇五栏共40次请求，39栏可用；ResNet贡献栏被格式/来源校验拒绝。随后保留v16方法范围试验和v17初稿/复核原始响应，不删除失败样本。最终方法专测跳过其他四栏，不能据此声称最终版本全五栏40/40成功。

目录说明：根各论文目录为首轮五栏；`final-method`是v16；`final-method-v17`是v17方法复核。后续格式修复补跑若单列目录，以汇总文件指明为准。每次请求包含无密钥messages、原始响应、usage和源码hash；最终引用经过原文锚点验证。token是服务端记账，包含推理；费用接口未提供，不推算金额。

## 质量观察与残余

相对B090五条碎片输入，模块与流程覆盖明显改善：SAM解释编码与decoder，Video-MME完整说明构建与评分，ResNet补入bottleneck，3DGS解释方向颜色的SH表示。v17 Video-MME已修复六域缺项与Gemini三模态条件泛化。

仍不能称为无事实错误：3DGS复核稿公式正确，但把“二次型随偏离中心衰减”写错，衰减的应为Gaussian权重；输出仍明显偏长（脚本字符数含英文、公式和引用，不能直接等同中文字数），部分仍有次要配置。模型复核不等于独立事实验证，合法alias也不等于论断被其支持。详细独立审阅见[semantic-review](B094/semantic-review.md)。
