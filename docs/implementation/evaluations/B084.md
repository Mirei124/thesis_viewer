# B084 PDF 原生链接浏览器验收

日期：2026-10-04。独立 Chromium、本机HTTP预览最终Chrome MV3构建，测试用storage／permissions API，自动概览关闭。使用用户给出的公开论文2609.38426（下载到/tmp/b084-2609.38426.pdf）、Video-MME和临时两页原生链接PDF。外链目标route模拟，验证浏览器真正打开的新标签地址和opener；没有模型调用。

- 2609.38426首页 PDF Link235R 原始rect[112.875,555.907,143.111,568.754]、url=https://github.com/Tier-Flow/LoopVL。页面实际anchor href及点击后popup URL一致，window.opener===null。32页连续文档共出现325个链接；截图/tmp/b084-code-link.png已由主agent确认code附近hover区域贴合文字。
- 两页fixture包括named target→第2页、explicit ref→第1页XYZ、numeric0→第1页Fit、missing named目标、javascript unsafeUrl、非active第2页外链。第2页带CropBox[10,20,390,580]与自身Rotate90。共6个允许链接，unsafe注释11R无交互区域。
- 第1页为active时，第2页外链一次点击打开https://example.test/passive；named、ref、numeric分别到页2、页1、页1。missing提示“This PDF link destination is unavailable.”，不跳错误页面。
- 800px高视口中，ref目标页内y=400：按PDF viewport和scroll-margin计算期望window.scrollY=282，实际282；验证不是仅跳页首。
- 150%手动缩放，rect[40,530,180,553]链接的left/top/width/height在0/90/180/270度分别为[60,70.5,210,34.5]、[795,60,34.5,210]、[330,795,210,34.5]、[70.5,330,34.5,210]，均与手工预期一致。
- 第2页CropBox及Rotate90叠加用户270度后的链接rect为[45,85.5,240,34.5]，canvas570×840，与总rotation0的CropBox预期一致。
- Video-MME第一页native20R与正文cite命中区重叠，点击native入口打开citation-popover，保持浮窗优先。鼠标拖选标题文字得到“Video-MME: ”，高亮／翻译工具条显示，非链接区域仍可选择。
- 临时fixture外链通过focus+Enter打开正确URL，有可见solid焦点轮廓；换文档后旧论文235R链接不存在。

子agent全套201项测试通过，主agent最终typecheck、双端build、git diff --check通过。临时脚本/tmp/b084-init.js、b084-fixture-test.js、b084-transform.js、b084-cite-select.js用于本次交互；长期证据以本记录为准。

边界：本批未做Firefox真实扩展交互、辅助技术屏幕阅读器或服务商模型回归。内链保持当前阅读zoom；不宣称复刻所有PDF destination缩放语义，不执行PDF脚本或表单动作。原无文字／密码／损坏／超限及其他未测PDF边界保持不变。
