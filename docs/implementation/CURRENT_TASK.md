## 第三部分：相关背景知识

- 用户确认边界：扫描件可继续阅读但不得虚构文本；密码、损坏和超限输入必须明确降级，超限在发模型前提示。
- 架构：初始工程限制为 100 MiB 或 500 页；文本缺失影响摘要/搜索，但不等于 PDF canvas 不可读。
- 现有入口：`src/pages/reader.tsx` 本地/URL 最终进入共用 PDF load；B004 permission request 必须仍在提交手势的第一个异步调用。
- 已验证：B007 全文搜索依赖各页文本，B005–B006 渲染/目录依赖 PDFDocumentProxy；新状态不能让旧文档或索引异步复活。
