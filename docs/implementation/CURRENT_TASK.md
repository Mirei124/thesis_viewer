- 总体任务／阶段：Hypha `0001`；M1 阅读核心与导入。

- 当前实现位置：阅读页保存 `PDFDocumentProxy`，逐页渲染 canvas/文字层，已有 request/render 竞态保护；没有全文文本索引或搜索 UI。
- 当前批次：B007；从所有页本地提取文本构建会话索引，提供搜索、匹配数量、上一/下一匹配和跳转。
- 与前后关系：为 M1 基础阅读补全全文查找；不承担 M2 稳定 Block、章节、坐标映射或持久化。
- 状态：待派发；执行 agent：待派发。

- 验证要求：使用至少 31 页 PDF 证明匹配可在非当前页找到并跳转；搜索不应由可见 DOM 决定。长文不必等到索引完成才能保持阅读控制可用。

## 第三部分：相关背景知识
