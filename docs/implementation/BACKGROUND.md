# 跨批次背景知识

[返回总体进度](../IMPLEMENTATION_PROGRESS.md)

- 实现目标与验收以已定稿规划为准。首版为阅读、两类摘要、高亮、cite 浮窗、选区翻译；其余候选功能默认不做。
- 三行摘要是引言末尾的三条 contributions，少背景；详细摘要 800–1500 中文字，覆盖问题／动机、具体方法、核心贡献、相对创新、实验与消融、证据支持的局限。
- cite 浮窗使用本地参考文献信息与已有本地摘要，不自动联网补全；摘要证据引用与正文书目引用区分。
- 技术基线为 WXT/TypeScript/React、PDF.js、本地 IndexedDB；独立扩展阅读页承载长任务，两端 MV3 构建。
- 当前研究证据只说明参考页 DOM 和部分原文已查看，不能当作本插件已实现或已测。参考站 cite 浮窗完整内容受额度限制未验证，生成提示词未经真实模型评测。

以上是委派时的事实来源摘要，不应把所有条目无差别塞给每个子 agent；主 agent 按当前目标选取相关内容。

详细设计以[规划入口](../planning/README.md)及其关联文档为准；新增无法从代码或文档恢复的持久结论保存到 Hypha。

- 2026-10-04 用户确认概览中的专有名词与专业术语保留来源英文拼写／大小写／缩写，不加中文译名；叙述仍中文。三行／普通详细／递进详细共用语言规则，提示版本更新隔离旧概览缓存。不改变选区翻译，不从中文来源反译编造英文。
